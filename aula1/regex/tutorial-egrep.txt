===============================================================================
 TUTORIAL PROGRESSIVO DE EXPRESSOES REGULARES COM egrep
===============================================================================
 Arquivo de dados: dados.txt (mesma pasta)
 Ferramenta......: egrep  (= grep -E, Extended Regular Expressions / ERE)

 COMO USAR
 ---------
 Abra o Git Bash (ou Cygwin/WSL) nesta pasta e execute cada comando na ordem.
 Leia a explicacao, RODE o comando, e confira se a saida bate com o esperado.

   cd /c/Users/orlando/clp/aula1/regex

 Se voce estiver no PowerShell, use "wsl egrep ..." ou abra o Git Bash.
 No Git Bash o egrep pode avisar "egrep is obsolescent"; use "grep -E" se
 preferir - e exatamente a mesma coisa.

 REGRA DE OURO: sempre coloque a expressao entre 'aspas simples', para que o
 shell nao interprete os metacaracteres ( * ? $ | \ ) antes do egrep.

===============================================================================
 NIVEL 0 - AS OPCOES QUE VOCE VAI USAR O TEMPO TODO
===============================================================================

 -n  mostra o numero da linha           -i  ignora maiusculas/minusculas
 -c  conta apenas quantas linhas casam  -v  inverte (mostra o que NAO casa)
 -o  mostra so o trecho que casou       -w  casa apenas palavras inteiras
 -l  lista so os nomes dos arquivos     -A/-B/-C n  mostra n linhas de contexto
 --color=auto  pinta o trecho que casou (muito util para aprender!)

-------------------------------------------------------------------------------
 00. Ver o arquivo inteiro numerado (ponto de partida)
-------------------------------------------------------------------------------
egrep -n '' dados.txt


===============================================================================
 NIVEL 1 - TEXTO LITERAL
===============================================================================

-------------------------------------------------------------------------------
 01. Busca literal: toda linha que contem a sequencia "casa"
     Repare que "casinha" NAO aparece e "descasar" APARECE (esta contido).
-------------------------------------------------------------------------------
egrep 'casa' dados.txt

-------------------------------------------------------------------------------
 02. Numerando as linhas encontradas
-------------------------------------------------------------------------------
egrep -n 'casa' dados.txt

-------------------------------------------------------------------------------
 03. Ignorando maiusculas/minusculas: pega casa, Casa e CASA
-------------------------------------------------------------------------------
egrep -in 'casa' dados.txt

-------------------------------------------------------------------------------
 04. Contando quantas linhas casaram (nao quantas ocorrencias!)
-------------------------------------------------------------------------------
egrep -ic 'casa' dados.txt

-------------------------------------------------------------------------------
 05. Invertendo: linhas que NAO contem "a"
-------------------------------------------------------------------------------
egrep -vn 'a' dados.txt

-------------------------------------------------------------------------------
 06. Palavra inteira: "sub" isolado, e nao "substituir"/"subir"/"insubstituivel"
-------------------------------------------------------------------------------
egrep -nw 'sub' dados.txt

-------------------------------------------------------------------------------
 07. Colorindo o casamento (use --color em TODOS os exercicios seguintes)
-------------------------------------------------------------------------------
egrep -n --color=auto 'gato' dados.txt


===============================================================================
 NIVEL 2 - O PONTO ( . ) : QUALQUER CARACTERE
===============================================================================

-------------------------------------------------------------------------------
 08. "." casa QUALQUER caractere (menos a quebra de linha)
     c.sa  ->  casa, cesa, c1sa, c sa ...
-------------------------------------------------------------------------------
egrep -n 'c.sa' dados.txt

-------------------------------------------------------------------------------
 09. Tres caracteres quaisquer entre "c" e "o"
-------------------------------------------------------------------------------
egrep -n 'c...o' dados.txt

-------------------------------------------------------------------------------
 10. Ponto LITERAL precisa de escape: \.  (aqui: "ponto.final")
     Compare os dois comandos abaixo e veja a diferenca.
-------------------------------------------------------------------------------
egrep -n 'ponto.final' dados.txt
egrep -n 'ponto\.final' dados.txt


===============================================================================
 NIVEL 3 - CLASSES DE CARACTERES [ ]
===============================================================================

-------------------------------------------------------------------------------
 11. Lista de opcoes: casa OU caso OU casu...
     [ao] = "um caractere que seja a ou o"
-------------------------------------------------------------------------------
egrep -n 'cas[ao]' dados.txt

-------------------------------------------------------------------------------
 12. Intervalo: qualquer digito de 0 a 9
-------------------------------------------------------------------------------
egrep -n '[0-9]' dados.txt

-------------------------------------------------------------------------------
 13. Varios intervalos na mesma classe: letra maiuscula ou digito
-------------------------------------------------------------------------------
egrep -n '[A-Z0-9]' dados.txt

-------------------------------------------------------------------------------
 14. Negacao com ^ DENTRO dos colchetes: linhas com algo que nao e
     letra, digito, espaco nem os separadores comuns
-------------------------------------------------------------------------------
egrep -n '[^a-zA-Z0-9 .,:_-]' dados.txt

-------------------------------------------------------------------------------
 15. Metacaracteres perdem o poder dentro da classe:
     [.] e um ponto literal; [*+?] sao literais tambem
-------------------------------------------------------------------------------
egrep -n '[*+]' dados.txt

-------------------------------------------------------------------------------
 16. Para incluir o proprio "-" na classe, coloque-o no fim: [0-9-]
-------------------------------------------------------------------------------
egrep -n '^[0-9-]+$' dados.txt


===============================================================================
 NIVEL 4 - ANCORAS ^ e $ (inicio e fim de linha)
===============================================================================

-------------------------------------------------------------------------------
 17. ^ = inicio da linha. Linhas que COMECAM com "casa"
     (agora "descasar" nao aparece mais)
-------------------------------------------------------------------------------
egrep -n '^casa' dados.txt

-------------------------------------------------------------------------------
 18. $ = fim da linha. Linhas que TERMINAM com "fim"
-------------------------------------------------------------------------------
egrep -n 'fim$' dados.txt

-------------------------------------------------------------------------------
 19. ^ e $ juntos = a linha inteira e exatamente isso
-------------------------------------------------------------------------------
egrep -n '^cat$' dados.txt

-------------------------------------------------------------------------------
 20. Linhas VAZIAS: comeco imediatamente seguido do fim
-------------------------------------------------------------------------------
egrep -n '^$' dados.txt

-------------------------------------------------------------------------------
 21. Linhas que comecam com espaco ou TAB
-------------------------------------------------------------------------------
egrep -n '^[ 	]' dados.txt

-------------------------------------------------------------------------------
 22. Linhas que terminam com um ou mais espacos (espaco invisivel no fim!)
-------------------------------------------------------------------------------
egrep -n ' +$' dados.txt


===============================================================================
 NIVEL 5 - QUANTIFICADORES  *  +  ?  {n,m}
===============================================================================

-------------------------------------------------------------------------------
 23. *  = zero ou mais.  "ba*nana" casa bnana, banana, baanana...
     CUIDADO: 'a*' sozinho casa TODAS as linhas (zero ocorrencias serve).
-------------------------------------------------------------------------------
egrep -n 'ba*nana' dados.txt

-------------------------------------------------------------------------------
 24. +  = uma ou mais. Linhas formadas SO por digitos
-------------------------------------------------------------------------------
egrep -n '^[0-9]+$' dados.txt

-------------------------------------------------------------------------------
 25. ?  = zero ou uma vez (opcional). Sinal de + ou - opcional antes do numero
-------------------------------------------------------------------------------
egrep -n '^[+-]?[0-9]+$' dados.txt

-------------------------------------------------------------------------------
 26. {n} = exatamente n vezes. Quatro digitos seguidos
-------------------------------------------------------------------------------
egrep -n '[0-9]{4}' dados.txt

-------------------------------------------------------------------------------
 27. {n,m} = de n a m vezes. Numeros de 3 a 5 digitos (linha inteira)
-------------------------------------------------------------------------------
egrep -n '^[0-9]{3,5}$' dados.txt

-------------------------------------------------------------------------------
 28. {n,} = n ou mais. Palavras/linhas com 10 ou mais digitos seguidos
-------------------------------------------------------------------------------
egrep -n '[0-9]{10,}' dados.txt

-------------------------------------------------------------------------------
 29. Numero decimal com parte fracionaria OPCIONAL (ponto ou virgula)
-------------------------------------------------------------------------------
egrep -n '^[+-]?[0-9]+([.,][0-9]+)?$' dados.txt

-------------------------------------------------------------------------------
 30. GULOSO (greedy): * e + pegam o MAIOR trecho possivel.
     Compare a saida dos dois comandos com -o:
-------------------------------------------------------------------------------
egrep -o '".*"' dados.txt
egrep -o '"[^"]*"' dados.txt


===============================================================================
 NIVEL 6 - ALTERNANCIA  |  E AGRUPAMENTO ( )
===============================================================================

-------------------------------------------------------------------------------
 31. | = "ou". Linhas com gato OU rato OU pato
-------------------------------------------------------------------------------
egrep -n 'gato|rato|pato' dados.txt

-------------------------------------------------------------------------------
 32. Parenteses delimitam a alternancia: "ga|ra|pa" + "to"
-------------------------------------------------------------------------------
egrep -n '(g|r|p)ato' dados.txt

-------------------------------------------------------------------------------
 33. Grupo + quantificador: o grupo inteiro se repete
     (ab)+ casa ab, abab, ababab
-------------------------------------------------------------------------------
egrep -n '^(ab)+$' dados.txt

-------------------------------------------------------------------------------
 34. Niveis de log de severidade alta (ancorado para nao pegar o texto)
-------------------------------------------------------------------------------
egrep -n '(ERROR|FATAL|WARN)' dados.txt

-------------------------------------------------------------------------------
 35. Precedencia: sem parenteses o | separa a expressao TODA.
     Compare - o primeiro casa "^inicio" ou "fim$"; o segundo casa a linha
     que e exatamente "inicio" ou exatamente "fim".
-------------------------------------------------------------------------------
egrep -n '^inicio|fim$' dados.txt
egrep -n '^(inicio|fim)$' dados.txt


===============================================================================
 NIVEL 7 - CLASSES POSIX  [[:...:]]
===============================================================================
 [[:digit:]] digitos      [[:alpha:]] letras       [[:alnum:]] letras+digitos
 [[:upper:]] maiusculas   [[:lower:]] minusculas   [[:space:]] espaco/tab
 [[:punct:]] pontuacao    [[:blank:]] espaco e tab [[:xdigit:]] hexadecimal
 ATENCAO: os colchetes duplos sao obrigatorios -> [[:digit:]] e nao [:digit:]

-------------------------------------------------------------------------------
 36. Linhas compostas SO de letras maiusculas e espacos
-------------------------------------------------------------------------------
egrep -n '^[[:upper:][:space:]]+$' dados.txt

-------------------------------------------------------------------------------
 37. Linhas com pontuacao
-------------------------------------------------------------------------------
egrep -n '[[:punct:]]' dados.txt

-------------------------------------------------------------------------------
 38. Somente alfanumericos e underline, linha inteira
-------------------------------------------------------------------------------
egrep -n '^[[:alnum:]_]+$' dados.txt

-------------------------------------------------------------------------------
 39. Numero hexadecimal no estilo 0x1F
-------------------------------------------------------------------------------
egrep -n '0[xX][[:xdigit:]]+' dados.txt


===============================================================================
 NIVEL 8 - LIMITES DE PALAVRA  \b  \< \>  \w \s
===============================================================================
 Extensoes do GNU grep (muito uteis, mas nao sao POSIX puro):
   \b  limite de palavra      \<  inicio de palavra    \>  fim de palavra
   \w  = [[:alnum:]_]         \W  o contrario
   \s  = espaco em branco     \S  o contrario

-------------------------------------------------------------------------------
 40. \b : "cat" como palavra isolada (nao pega "concatenar" nem "scatter")
-------------------------------------------------------------------------------
egrep -n '\bcat\b' dados.txt

-------------------------------------------------------------------------------
 41. \< : palavras que COMECAM com "sub"
-------------------------------------------------------------------------------
egrep -n '\<sub' dados.txt

-------------------------------------------------------------------------------
 42. \> : palavras que TERMINAM com "ato"
-------------------------------------------------------------------------------
egrep -n 'ato\>' dados.txt

-------------------------------------------------------------------------------
 43. \w e \s : uma palavra, um espaco, outra palavra (extrai o par com -o)
-------------------------------------------------------------------------------
egrep -o '\w+\s\w+' dados.txt


===============================================================================
 NIVEL 9 - BACK-REFERENCES  \1 \2
===============================================================================
 \1 significa "o mesmo texto que o grupo 1 casou". Serve para achar repeticoes.

-------------------------------------------------------------------------------
 44. Linha formada por um trecho repetido duas vezes (abab, abcabc, 1212...)
-------------------------------------------------------------------------------
egrep -n '^(.+)\1$' dados.txt

-------------------------------------------------------------------------------
 45. Palavra repetida em sequencia ("palavra palavra", "o o gato")
-------------------------------------------------------------------------------
egrep -n '\b(\w+) \1\b' dados.txt

-------------------------------------------------------------------------------
 46. Letra dobrada (rr, ss, ff, nn...)
-------------------------------------------------------------------------------
egrep -n '([a-z])\1' dados.txt


===============================================================================
 NIVEL 10 - CASOS REAIS: VALIDACAO E EXTRACAO
===============================================================================

-------------------------------------------------------------------------------
 47. E-MAIL (versao didatica, boa o suficiente para o dia a dia)
-------------------------------------------------------------------------------
egrep -in '[[:alnum:]._%+-]+@[[:alnum:].-]+\.[a-z]{2,}' dados.txt

-------------------------------------------------------------------------------
 48. Extraindo SO o e-mail com -o, e so o dominio com -o + sed mental
-------------------------------------------------------------------------------
egrep -oi '[[:alnum:]._%+-]+@[[:alnum:].-]+\.[a-z]{2,}' dados.txt

-------------------------------------------------------------------------------
 49. DATA ISO completa: 2026-08-14 (com mes 01-12 e dia 01-31 validados)
     Repare que "2026-13-45" e corretamente rejeitada.
-------------------------------------------------------------------------------
egrep -on '[0-9]{4}-(0[1-9]|1[0-2])-(0[1-9]|[12][0-9]|3[01])' dados.txt

-------------------------------------------------------------------------------
 50. DATA BR: 14/08/2026 ou 14-08-2026 (separador consistente via \1)
-------------------------------------------------------------------------------
egrep -on '(0[1-9]|[12][0-9]|3[01])([/-])(0[1-9]|1[0-2])\2[0-9]{4}' dados.txt

-------------------------------------------------------------------------------
 51. HORA valida 00:00 a 23:59, com segundos opcionais ("25:99" e rejeitada)
-------------------------------------------------------------------------------
egrep -on '\b([01][0-9]|2[0-3]):[0-5][0-9](:[0-5][0-9])?\b' dados.txt

-------------------------------------------------------------------------------
 52. IP v4 ingenuo (aceita 999.999.999.999 - errado de proposito!)
-------------------------------------------------------------------------------
egrep -on '([0-9]{1,3}\.){3}[0-9]{1,3}' dados.txt

-------------------------------------------------------------------------------
 53. IP v4 CORRETO: cada octeto de 0 a 255 (rejeita 999.999.999.999)
-------------------------------------------------------------------------------
egrep -on '\b(([0-9]|[1-9][0-9]|1[0-9]{2}|2[0-4][0-9]|25[0-5])\.){3}([0-9]|[1-9][0-9]|1[0-9]{2}|2[0-4][0-9]|25[0-5])\b' dados.txt

-------------------------------------------------------------------------------
 54. TELEFONE BR com DDD entre parenteses, 8 ou 9 digitos
-------------------------------------------------------------------------------
egrep -on '\([0-9]{2}\) ?[0-9]{4,5}-[0-9]{4}' dados.txt

-------------------------------------------------------------------------------
 55. CPF formatado 000.000.000-00
-------------------------------------------------------------------------------
egrep -on '[0-9]{3}\.[0-9]{3}\.[0-9]{3}-[0-9]{2}' dados.txt

-------------------------------------------------------------------------------
 56. CEP nos dois formatos: 01310-100 e 20040030
-------------------------------------------------------------------------------
egrep -on '\b[0-9]{5}-?[0-9]{3}\b' dados.txt

-------------------------------------------------------------------------------
 57. URL com protocolo, porta e caminho opcionais
-------------------------------------------------------------------------------
egrep -on 'https?://[[:alnum:].-]+(:[0-9]+)?(/[[:alnum:]._/?=&-]*)?' dados.txt

-------------------------------------------------------------------------------
 58. PLACA de veiculo: modelo antigo ABC-1234 e Mercosul BRA2E19
-------------------------------------------------------------------------------
egrep -on '\b([A-Z]{3}-[0-9]{4}|[A-Z]{3}[0-9][A-Z][0-9]{2})\b' dados.txt


===============================================================================
 NIVEL 11 - ANALISE DE LOG (juntando tudo)
===============================================================================

-------------------------------------------------------------------------------
 59. So as linhas de log (que comecam com data)
-------------------------------------------------------------------------------
egrep -n '^[0-9]{4}-[0-9]{2}-[0-9]{2} ' dados.txt

-------------------------------------------------------------------------------
 60. Erros e falhas fatais
-------------------------------------------------------------------------------
egrep -n '^[0-9-]+ [0-9:]+ (ERROR|FATAL)' dados.txt

-------------------------------------------------------------------------------
 61. Contexto: 1 linha antes e 1 depois de cada ERROR (para entender a causa)
-------------------------------------------------------------------------------
egrep -n -C1 'ERROR' dados.txt

-------------------------------------------------------------------------------
 62. Extraindo so os horarios dos eventos de login
-------------------------------------------------------------------------------
egrep -o '[0-9]{2}:[0-9]{2}:[0-9]{2}(?= )' dados.txt 2>/dev/null || \
egrep -o '[0-9]{2}:[0-9]{2}:[0-9]{2} INFO' dados.txt
     # NOTA: egrep NAO tem lookahead (?=...). Por isso a segunda forma.
     # Lookahead so existe em PCRE: use "grep -P" (se disponivel).

-------------------------------------------------------------------------------
 63. Percentuais de uso acima de 80%
-------------------------------------------------------------------------------
egrep -on '(8[0-9]|9[0-9]|100)%' dados.txt

-------------------------------------------------------------------------------
 64. Quantos usuarios distintos aparecem no log (pipeline classico)
-------------------------------------------------------------------------------
egrep -o 'usuario [a-z]+' dados.txt | sort -u

-------------------------------------------------------------------------------
 65. Contando ocorrencias por nivel de log
-------------------------------------------------------------------------------
egrep -o '(INFO|DEBUG|WARN|ERROR|FATAL)' dados.txt | sort | uniq -c | sort -rn


===============================================================================
 NIVEL 12 - CSV E OUTRAS TECNICAS
===============================================================================

-------------------------------------------------------------------------------
 66. Linhas do CSV: 4 campos separados por virgula
-------------------------------------------------------------------------------
egrep -n '^[^,]+,[^,]+,[^,]+,[^,]+$' dados.txt

-------------------------------------------------------------------------------
 67. Pessoas com salario acima de 5000 (5, 6, 7, 8 ou 9 mil)
-------------------------------------------------------------------------------
egrep -n ',[5-9][0-9]{3}\.[0-9]{2}$' dados.txt

-------------------------------------------------------------------------------
 68. Primeiro campo (nome) de cada linha do CSV
-------------------------------------------------------------------------------
egrep '^[A-Z][a-z]+ [A-Z][a-z]+,' dados.txt | egrep -o '^[^,]+'

-------------------------------------------------------------------------------
 69. Varios padroes de uma vez com -e (equivale ao | )
-------------------------------------------------------------------------------
egrep -n -e 'CPF' -e 'CNPJ' -e 'CEP' dados.txt

-------------------------------------------------------------------------------
 70. Buscando em varios arquivos, recursivamente, so os nomes dos arquivos
-------------------------------------------------------------------------------
egrep -rl 'egrep' .


===============================================================================
 ARMADILHAS COMUNS (leia antes da prova!)
===============================================================================
 1. Esquecer as aspas simples: egrep a|b arquivo -> o shell entende um PIPE.
 2. ERE nao usa \( \) \{ \}: isso e BRE (grep sem -E). Em egrep use ( ) { }.
 3. "." dentro de [ ] e literal: [.] nao precisa de escape.
 4. * casa ZERO ocorrencias -> '[0-9]*' casa qualquer linha, inclusive vazia.
 5. egrep casa SUBSTRING: use ^ e $ quando quiser validar a linha inteira.
 6. Nao existe lookahead/lookbehind em ERE. Use grep -P (PCRE) se precisar.
 7. Arquivos com quebra de linha do Windows (CRLF) tem um \r invisivel antes
    do fim da linha, e 'texto$' falha. Diagnostique e corrija com:
       egrep -c $'\r' dados.txt
       tr -d '\r' < dados.txt > dados-unix.txt
 8. -c conta LINHAS que casam, nao o total de ocorrencias.
    Para contar ocorrencias:  egrep -o 'padrao' arquivo | wc -l
